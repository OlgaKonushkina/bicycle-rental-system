# Bicycle Rental System - Data Engineer Test Task

## Описание
Система учета аренды велосипедов с аналитикой и расчетом премий сотрудников.

## Файлы:
- `BicycleRental_FullSetup.sql` - настройка базы (таблицы, данные, запросы, витрина)
- `BicycleRental.bak` - бэкап базы с тестовыми данными

## Содержит:
- 7 таблиц
- 5 аналитических запросов
- Витрину для премий
- Процедуры расчетов
