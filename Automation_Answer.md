# Варианты автоматизации загрузки витрины

Основной способ - SQL Server Agent. Это стандартный планировщик заданий в SQL Server.

## Как настроить:
1. В SSMS создаем новое задание в SQL Server Agent
2. Добавляем шаг с командой: EXEC LoadStaffBonusMart
3. Настраиваем расписание на ежедневное выполнение (например, в 23:00)

## Преимущества:
- Не требует дополнительных инструментов
- Надежная работа
- Есть мониторинг и уведомления

## Альтернативные варианты:

### PowerShell + Планировщик заданий Windows:
- Подходит если нет доступа к SQL Agent
- Нужно написать скрипт с вызовом процедуры

### SSIS пакеты:
- Для сложных ETL-процессов
- Избыточно для нашей задачи

Для регулярной загрузки витрины с премиями SQL Server Agent - наиболее простое и подходящее решение.
